
# A modern, free document editor for you


https://github.com/user-attachments/assets/a23beba4-73c5-44d2-9433-ee5d61378a4b


Welcome to an open source project I've been working on, where its goal is to make a modern, free, and powerful word processor.

Features implemented are:

- 🕒 A Version **history and control** system
- 📄 **File saving** supporting .txt and .rtf files
- ⚙️ Special effects such as entropy based/random text generation
  
## How to run this editor?

To run this editor, download the files provided and simply **drag and drop it** into your browser.

You can also:

- Open this in **IDEs** such as **VSCode**
